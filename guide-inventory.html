Inventory & Storage

An Echoes of Creation guide

On this page

  1. Weight System
  2. Item Stacking
  3. Comparing Gear
  4. Storage (Bank)

Weight System

Your inventory is limited by weight, not slots.

Max Weight = 50 + VIT x 5 + (Level - 1) x 5.

Each item has a weight value multiplied by its quantity.

Item Stacking

Consumables and materials stack up to their max stack limit.

Gear items never stack (1 per slot).

If you're over the weight limit, you can't pick up more items.

Comparing Gear

Open any gear in your bag and the piece you have equipped in that slot appears side by side with it, so the two read like facing pages. A "Compared to" line sums up the stat deltas — green numbers are gains, red are losses.

The comparison includes both items' upgrade levels and socketed gems.

Genesis innates and accessory enchants are listed in their own sections and are not part of the delta numbers.

Rings and earrings compare against the slot equipping would actually fill (an empty slot first).

On narrow screens the equipped card is hidden and the delta line carries the comparison alone.

Storage (Bank)

Talk to Keeper Nessa in the village to access storage.

Starts at 50 storage slots.

Expand it with Storage Expansion from the Lumina Shop: +4 slots each (25 Lumina), up to 450 slots max.

Expansions are account-wide — every character shares the same expanded bank.

Deposit items to free up inventory weight.

Storage is shared across ALL characters on your account — deposit on one character and withdraw on another.

Storage persists across all maps and sessions.

Use the category filters (All / Gear / Potions / Materials / Gems / Special) at the top to narrow both your inventory and storage to one type at once.

Type in the Search box to find an item by name across both panes.

Sort by Grade arranges both panes by grade (highest first), then A–Z — this only changes the view, so nothing is moved or lost.

Deposit Same Items moves every inventory item that already has a match in storage.
